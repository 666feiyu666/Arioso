帮助说明

这里简单说明 MoodMic 怎么用、它在做什么，以及工作流里的几种创作方式。

MoodMic 是什么

它把"此刻的心情"变成一段属于你的音乐。你只需要用日常语言说出感受，不用懂乐理。

怎么用

  1. 说出心情：写几句话，或点选几个贴近此刻的词。
  2. 选择形态：一首单曲，或一张专辑。
  3. 确认方向：可以继续补充想法，也可以直接采纳当前方向。
  4. 等待创作：界面会显示当前进度。
  5. 试听结果：播放、下载，或回到工作流继续管理。

单曲与专辑

单曲是一段完整的瞬间；专辑是一组有共同情绪方向的曲子，各有性格，又能连在一起听。两种都可以先按默认设置，之后随时调整。

工作流

顶部的"工作流"页签里，有四种更专门的创作方式：

  • 无语料生成：直接使用模型已有的音乐知识。
  • Jazz 语料生成：先检索本地 Jazz 语料再编曲。
  • 管弦乐作曲：规划统一主题与多个乐章。
  • 多曲目专辑：一次生成整批候选曲，挑选后组成专辑。

开始之前

生成音乐需要 API Key。在工作流页面左下角的"设置"里填入即可；Key 只保存在本机。
