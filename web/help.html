帮助说明

这里简单说明 MoodMic 怎么用、它在做什么，以及工作流里的几种创作方式。

MoodMic 是什么

它把"此刻的心情"变成一段属于你的音乐。你只需要用日常语言说出感受，不用懂乐理。

怎么用

  1. 描述心情与音乐：在对话里用几句话写下此刻的心情和想要的音乐。
  2. 讨论方向：继续聊，或把共识整理成作曲提示词。
  3. 确认心情：方向确定后会读出一个心情（颜色和词），你可以改。
  4. 开始创作：确认后生成这一首单曲。
  5. 试听结果：播放并下载，也可以在「心情日历」里回看并打开对应的对话。

心情颜色

MoodMic 用四种颜色表示心情，每种颜色下是一组相近的情绪词。颜色只是分类和选择的方式：

  • 红色 —— 高能量、不愉快：焦虑、愤怒、烦闷、不堪重负。
  • 黄色 —— 高能量、愉快：兴奋、喜悦、充满活力、热情。
  • 蓝色 —— 低能量、不愉快：难过、孤单、疲惫、气馁。
  • 绿色 —— 低能量、愉快：平静、满足、放松、安宁。

一首单曲

MoodMic 每次把一段心情写成一首完整的单曲。想要多乐章、专辑等更专门的创作，可以在「工作流」页签里进行。

工作流

顶部的"工作流"页签里，有四种更专门的创作方式：

  • 无语料生成：直接使用模型已有的音乐知识。
  • Jazz 语料生成：先检索本地 Jazz 语料再编曲。
  • 管弦乐作曲：规划统一主题与多个乐章。
  • 多曲目专辑：一次生成整批候选曲，挑选后组成专辑。

开始之前

生成音乐需要 API Key。在工作流页面左下角的"设置"里填入即可；Key 只保存在本机。
